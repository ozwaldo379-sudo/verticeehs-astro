# Design System: Vértice EHS — Clinical Sovereign v3.0
**Project Identity:** Vértice EHS (Manifiesto + Catalog — Astro)
**Source of Truth:** Generated by Google AI Studio (Stitch). Indexed for AI context.

## 1. Visual Theme & Atmosphere
**Estética: "Clinical Editorial" / "Sovereign Lab"**
La interfaz transmite autoridad, precisión quirúrgica y urgencia controlada. Diseño denso pero sumamente estructurado, similar a un reporte forense de alta gama.
- **Atmósfera:** Oscura, inmersiva, técnica.
- **Filosofía Visual:** "No-Line Rule" — El espacio y el contraste (Tonal Layering) separan los elementos, no los bordes de 1px.
- **Ambient Depth:** El sistema de partículas global aporta atmósfera digital sin distraer del contenido técnico.

## 2. Color Palette & Roles
*   **Deep Void Base** (`#030508`): Fondo primario. Negro casi absoluto sin tintes azules.
*   **Surface** (`#101418`): Fondo base del sistema de diseño AI Studio.
*   **Charcoal Surface** (`#0A0E14`): Tarjetas, contenedores y fondos secundarios (Tonal Layering).
*   **Primary / Hazard Green** (`#70de72` / `#2E9E3C`): Acento primario. Acciones seguras, botones, progreso positivo.
*   **Alert Orange** (`#E86650`): Riesgo/urgencia. Advertencias directas y bordes animados de impacto.
*   **Muted Steel** (`#94A3B8`): Texto secundario y descriptivo.
*   **Sovereign White** (`#F8FAFC`): Texto principal de alto contraste.
*   **Logo Blue** (`#1A5CE6`): Uso exclusivo en gradiente global y sistema de partículas.

## 3. Typography Rules
*   **Headings:** `Manrope`, sans-serif. Pesos `Bold` / `ExtraBold`. `letter-spacing: -0.02em`.
*   **Body:** `Inter`, sans-serif. Pesos `Regular (400)` / `Medium (500)`. `line-height: 1.6`.

## 4. Component Stylings
*   **ADN Glass Cards:** `rounded-2xl`, `backdrop-filter: blur(20px)`, fondo `rgba(10,14,20,0.75)`. Shadow: `0 4px 30px rgba(0,0,0,0.4)`. Hover: `translateY(-4px)`.
*   **Botones Primarios:** `rounded-full`. Fondo Hazard Green, texto blanco. Shadow: `0 8px 24px rgba(46,158,60,0.25)`.
*   **Animated Borders (The Design Spell):** Gradiente cónico rotando. Solo para elementos críticos/featured.

## 5. Layout Principles
*   **Bento Grid:** Estructuras asimétricas para información densa.
*   **Breathable Density:** Secciones separadas por `py-32` / `8rem`.
*   **Physicality (ScrollSpy & 3D):** Micro-animaciones de entrada `y: 20 → y: 0` con stagger.

## 6. Ambient Particle System (Design Spell — GLOBAL)
*   **Componente:** `src/components/ParticleBackground.astro`. Inyectado en `Layout.astro` — aplica a **todas** las páginas.
*   **Tecnología:** Canvas 2D API (Vanilla JS). Zero dependencias externas. GPU-accelerated con `requestAnimationFrame`. Respeta `prefers-reduced-motion`.
*   **Física (AI Studio):**
    *   100 partículas circulares, radio `0.8–2.2px`.
    *   Velocidad `±0.18 px/frame`. Bouncing en bordes del viewport.
    *   Conexiones entre partículas a distancia `< 100px`: `rgba(148,163,184, 0.04)`, lineWidth `0.5`.
*   **Colores de Partículas (tricolor logo):**
    *   `rgba(46, 158, 60, 0.3)` — Hazard Green
    *   `rgba(26, 92, 230, 0.3)` — Logo Blue
    *   `rgba(248, 250, 252, 0.3)` — Sovereign White
*   **Regla:** Todo contenido vive en `z-index: 1+` sobre el canvas (`z-index: 0`).

## 7. Gradient Title System (Design Spell — GLOBAL)
*   **Paleta:** `#2E9E3C → #1A5CE6 → #F8FAFC → #1A5CE6 → #2E9E3C`.
*   **Animación:** `gradient-shift` keyframe. `background-size: 250% 250%`. Ciclo de 8s suave.
*   **Clases CSS (`global.css`):**
    *   `.gradient-title` — Uso principal. Para `<span>` dentro de H1/H2.
    *   `.gradient-title-subtle` — Versión desaturada para acentos secundarios.
    *   `.gradient-accent` — Verde dominante. Para H3 o palabras clave.
*   **Regla:** Aplicar solo a *una* palabra o frase por sección.
